# 차근차근 탐험단 QA 체크리스트

| 항목 | 적는 곳 |
|---|---|
| 시험한 날 | |
| 시험한 사람 | |
| 앱 버전(커밋) | `git log -1 --oneline` 결과 |
| APK 종류 | 로컬 주소 빌드(기본, 제출 APK 포함) / 배포 서버 주소 빌드 |
| 기기 | Pleos 에뮬레이터(Pleos Connect v2.1.0 APIs, 2560 × 1440, 160 dpi) / 실차 |
| 이야기 서버 | 팀 배포 서버 / 로컬 서버 / 서버 없음 |

**결과 적는 법**: 통과는 `O`, 실패는 `X`, 확인하지 못했으면 `-`. 실패하면 [버그_기록_양식.md](버그_기록_양식.md)로 버그를 하나 적고 그 번호(예: `BUG-003`)를 "버그" 칸에 씁니다.

**서버 주소는 빌드할 때 정해집니다.** 기본 빌드(제출 APK 포함)는 `http://127.0.0.1:8787`을 보고, 배포 서버를 보려면 `-PstoryUrl=<팀 배포 주소>`로 따로 빌드합니다(`car/app/build.gradle.kts`). 그래서 아래의 "서버 끊기"(`adb reverse --remove tcp:8787`)는 **기본 빌드에서만** 듣습니다. 배포 서버 빌드로는 서버 없는 시험(D-05, F-03, I 절)을 하지 않습니다.

**돈이 드는 시험**: 새 AI 이야기 한 편은 대본, 그림, 목소리까지 합쳐 돈이 들고 1분쯤 걸립니다. 같은 선택(친구, 나이, 시간, 장소, 종류)이면 창고에 저장된 이야기가 나오므로, 새 이야기가 꼭 필요한 시험(D 절)만 새 선택으로 하고 나머지는 기본 빌드에서 서버를 끊고 기본 이야기로 봅니다.
