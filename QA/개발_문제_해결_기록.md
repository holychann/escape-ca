# 차근차근 탐험단 개발 중 문제와 해결 기록

2026년 11월 2일부터 11월 27일까지 차근차근 탐험단을 만들면서 실제로 겪은 문제를 분야별로 모았습니다. 저장소 커밋 기록과 작업 대화 기록을 함께 보고 정리했습니다. 항목마다 **문제**(무엇이 보였나), **원인**(왜 그랬나), **해결**(어떻게 고쳤나), **근거**(커밋이나 날짜)를 적었습니다. 원인을 확인하지 못한 것은 "확인 못 함"으로 두었습니다. QA 때 같은 문제가 다시 나오는지 확인하는 회귀 목록으로도 씁니다([QA_체크리스트.md](QA_체크리스트.md)의 R 절).

## 아직 남은 것

**버그나 확인할 것**
- 지난 자막 버튼을 처음 누르면 열리지 않은 적이 있음. 원인을 찾지 못함(11-27).
- 시트 열선 되돌리기에서 차가 약 10초 뒤에 성공을 알렸는데, 앱은 3초 안에 답이 없으면 실패로 처리함(11-25).
- 시작할 때 차가 에어컨이나 열선 값을 아직 알려 주지 않았으면 끝날 때 그 값은 되돌리지 않음(의도한 동작).
- 다음 화면에서 "탐험 시작"을 누르기 전부터 놀이 시간이 흐름(11-27).
- 화면 키보드가 준비 칸을 가림.
- 영어 글자 수 문제의 철자 숨김은 단위 테스트로만 확인함. 서버가 쓴 이야기 앞부분에 영어 단어가 따로 나오면 철자가 그대로 보일 수 있음.
- 문제은행 힌트 일부에 "차 안"이 남아 있음("숫자가 커지면 차 안이 포근해져"). 이 말을 막는 검사는 푼 뒤 한 줄에만 있음.
- 자막 줄바꿈이 "익어 / 가는"처럼 보조 용언에서 어색하게 끊기는 경우가 남음.
- `에뮬레이터_테스트_방법.md`에 지금 앱과 다른 내용이 남아 있음: 정답 유지 시간 "1초"(앱은 2.5초, 화면 안내 "셋을 셀 동안"이 맞음), 이야기 한 편 "약 7원"(5-17), 시작 버튼 "이 이야기로 시작하기"(지금은 "소원 빌기"), 공조 전원을 "CLIMATE 카드의 Power"로 켬(2-7, Emulation Controls의 HVAC Power가 맞음).

**그림**

- 시험 그림의 구름, 언덕, 조명이 견본과 비슷해지는 경향이 있음.
