# 차근차근 탐험단 버그 기록 양식

QA 중 실패한 항목은 버그 하나당 아래 양식 하나를 복사해 이 파일 맨 아래 "버그 기록" 절에 붙입니다. 번호는 `BUG-001`부터 차례로 매기고, 그 번호를 [QA_체크리스트.md](QA_체크리스트.md)의 "버그" 칸에도 적습니다.

## 적는 기준

**심각도**

| 등급 | 뜻 | 예 |
|---|---|---|
| 치명 | 앱이 꺼지거나, 안전 규칙이 깨지거나, 놀이를 끝낼 수 없음 | 자막 때문에 앱이 꺼짐, 주행 중에 놀이가 멈추지 않음, 차를 되돌리지 못함 |
| 높음 | 주요 기능이 틀리게 동작하지만 다른 방법으로 넘어갈 수 있음 | 정답을 넣어도 정답이 안 됨, 이어 하기가 눌리지 않음 |
| 보통 | 기능은 되지만 아이나 보호자가 헷갈리거나 어색함 | 자막이 1초 넘게 앞섬, 이름을 잘못 읽음, 문구가 어색함 |
| 낮음 | 보기에만 거슬림 | 글자 한 줄이 살짝 잘림, 여백이 고르지 않음 |

**재현 빈도**: 매번 / 가끔(몇 번 중 몇 번) / 한 번만

**분야**: 첫 실행, 준비 화면, 시작 조건과 안전, 이야기 만들기, 퍼즐, 목소리, 자막, 마무리(처음 설정으로), 이어 하기, 그림, 화면, 서버, 배포

**상태**: 새로 찾음 → 확인함(다른 사람도 재현) → 고치는 중 → 고침(커밋) → 다시 확인함 → 닫음. 버그가 아니면 "버그 아님"으로 닫고 이유를 적습니다.

**주의**: 로그나 스크린샷에 API 키, 서버 주소, 계정 정보가 보이면 지우고 붙입니다. 서버 `.env` 내용은 붙이지 않습니다.

## 쓴 예

```markdown
### BUG-001 퍼즐 중 끝내기를 눌러도 친구가 퍼즐 대사를 끝까지 읽음

| 항목 | 내용 |
|---|---|
| 찾은 날, 찾은 사람 | 2026-11-27, QA 담당 |
| 체크리스트 ID | F-08 |
| 분야 | 목소리 |
| 심각도 | 보통 |
| 재현 빈도 | 매번 |
| 앱 버전(커밋) | ea5edbc |
| 기기 | 에뮬레이터 |
| 이야기 서버 | 팀 배포 서버 |
| 놀이 조건 | 반테, 7~9세, 10분, 공룡 섬, 보물찾기 |
| 이야기 ID | (창고 이야기, 로그의 ID) |
| 차 시작 값 | P, 2단, 22도, 없음, 꺼짐, 0 |
| 상태 | 닫음 |

**재현 순서**
1. 퍼즐 1이 시작되고 친구가 문제를 읽기 시작함
2. 다 읽기 전에 부모 화면 "끝내기"를 누름

**기대한 결과**
목소리가 바로 멈추고 처음 설정으로 화면으로 넘어감

**실제 결과**
처음 설정으로 화면으로 넘어갔지만 친구가 문제를 끝까지 읽고 자막도 남음

**고친 내용**
- 커밋: c3f3d45 (끝내기에서 목소리를 바로 멈춤)
- 다시 확인한 날, 사람: 2026-11-27, 에뮬레이터에서 확인
```
