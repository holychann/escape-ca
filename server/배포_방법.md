# 이야기 서버 배포 (AWS Lightsail 인스턴스)

이야기 서버를 Lightsail 인스턴스 한 대에 Docker로 띄웁니다. 앞에 Caddy를 두어 HTTPS 인증서를 자동으로 받습니다.

```
차 앱 ──HTTPS──▶ Caddy (80, 443) ──▶ story (8787, 바깥에 열지 않음) ──▶ Gemini / Claude
                                        └ /data 볼륨: episodes.jsonl, reports.jsonl, 그림
```

| 파일 | 하는 일 |
|---|---|
| `Dockerfile` | 서버 이미지. root가 아닌 사용자로 uvicorn 프로세스 하나만 띄웁니다 |
| `.dockerignore` | `.env`, `.venv`, `data/`, 테스트를 이미지에서 뺍니다 (API 키가 이미지에 들어가지 않게) |
| `compose.yaml` | 서버와 Caddy, 볼륨 3개 (`story-data`, `caddy-data`, `caddy-config`) |
| `Caddyfile` | HTTPS, HTTP→HTTPS 넘기기, 요청 본문 64KB 제한, 응답 대기 6분 |

## 1. 인스턴스 만들기 (Lightsail 콘솔)

1. **인스턴스 생성**: 리전 **서울(ap-northeast-2)**, 플랫폼 **Linux/Unix**, 청사진 **OS 전용 → Ubuntu 24.04 LTS**
2. **요금제**: 메모리 **1GB 이상**. 그림 여러 장을 한꺼번에 다루면 512MB는 빠듯합니다. 요금은 콘솔에서 확인하세요.
3. **고정 IP**: 네트워킹 탭에서 고정 IP를 만들어 이 인스턴스에 붙입니다. 붙이지 않으면 재시작할 때 IP가 바뀌어 인증서와 앱 주소가 깨집니다.
4. **방화벽**(인스턴스 → 네트워킹 → IPv4 방화벽): **HTTPS(TCP 443)** 를 추가합니다. SSH(22)와 HTTP(80)는 기본으로 열려 있습니다. 80은 인증서 발급에 쓰니 닫지 마세요.

## 2. 주소 정하기

인증서는 IP가 아니라 이름에 발급되므로 주소가 하나 필요합니다.

- **도메인이 있으면**: DNS에 A 레코드(예: `story.example.com`)로 고정 IP를 넣습니다.
- **도메인이 없으면**: IP의 점을 줄표로 바꾼 `13-125-1-2.sslip.io` 같은 주소를 씁니다. 따로 등록할 필요가 없습니다. 다만 남의 서비스에 기대는 것이라, 오래 쓸 거면 도메인을 권합니다.

## 3. 서버에 Docker 설치

콘솔의 **SSH를 사용하여 연결**(브라우저 터미널)로 들어가서:

```bash
sudo apt-get update
```

```bash
sudo apt-get install -y docker.io docker-compose-v2 git
```

```bash
sudo usermod -aG docker ubuntu
```

`usermod` 뒤에는 SSH 창을 닫았다가 다시 열어야 `sudo` 없이 `docker`를 쓸 수 있습니다.

## 4. 코드 받기와 .env

서버에는 `server/` 폴더만 있으면 됩니다. 차 앱 코드, APK(약 43MB), 앱 그림은 받지 않도록 필요한 폴더만 받습니다.

```bash
git clone --filter=blob:none --sparse https://github.com/holychann/escape-ca.git
```

```bash
cd escape-ca && git sparse-checkout set server && cd ..
```

`ls escape-ca`를 했을 때 `server`와 루트 문서 몇 개만 보이면 됩니다. 나중에 `git pull`을 해도 `server/`만 받습니다.

저장소가 비공개면 GitHub 토큰이나 배포 키가 있어야 받을 수 있습니다. 토큰을 쓰기 어렵다면 PC에서 `server` 폴더를 `scp`로 올려도 됩니다(`.env`, `.venv`, `data`는 빼고).

```bash
cd escape-ca/server && cp .env.example .env && chmod 600 .env && nano .env
```

`.env`에 채울 것:

- `GEMINI_API_KEY` 또는 `ANTHROPIC_API_KEY` (Claude만 쓰면 `STORY_PROVIDER=claude`도)
- `STORY_DOMAIN=` 2번에서 정한 주소 (예: `13-125-1-2.sslip.io`). `#`을 지우고 줄 맨 앞에서 시작하세요.

`.env`는 서버에서만 만들고, 저장소나 메시지에 붙이지 않습니다.

## 5. 띄우기

```bash
docker compose up -d --build
```

처음에는 이미지를 만들고 인증서를 받느라 1~2분 걸립니다. 확인:

```bash
docker compose ps
```

```bash
curl https://13-125-1-2.sslip.io/health
```

`{"ok":true,"pictures":true}`가 나오면 됩니다. Gemini 키가 없거나 `IMAGE_MODEL=off`면 `pictures`는 `false`입니다. 인증서를 못 받으면 `docker compose logs caddy`를 보세요. 대개 방화벽 80/443이 닫혀 있거나 주소가 고정 IP를 가리키지 않아서입니다.

## 6. 앱을 배포 서버에 붙이기

PC에서 배포 주소로 APK를 다시 빌드합니다. 주소가 `https://`면 앱의 평문 HTTP 허용은 자동으로 꺼집니다.

```bash
cd car && ./gradlew assembleRelease -PstoryUrl=https://13-125-1-2.sslip.io
```

이때는 `adb reverse`가 필요 없습니다.

## 운영

| 할 일 | 명령 (`escape-ca/server`에서) |
|---|---|
| 코드 바꾼 뒤 다시 배포 | `git pull && docker compose up -d --build` |
| 서버 로그 | `docker compose logs -f story` |
| 부모 신고 보기 | `docker compose exec story cat /data/reports.jsonl` |
| 기록과 그림 백업 | `docker compose cp story:/data ./backup-$(date +%F)` |
| 재시작 / 멈춤 | `docker compose restart` / `docker compose down` |

- **볼륨을 지우지 마세요**: `docker compose down -v`는 기록, 신고, 그림, 인증서를 모두 지웁니다. 인증서를 너무 자주 다시 받으면 Let's Encrypt 발급 횟수 제한에 걸립니다.
- **프로세스는 하나만**: 하루 생성 제한(설치당 20편, 주소당 200편)을 메모리에서 셉니다. uvicorn `--workers`를 늘리거나 서버를 여러 대 띄우면 제한이 나뉘어 셉니다. 재시작하면 그날 횟수는 0부터 다시 셉니다.
- **8787을 바깥에 열지 마세요**: 서버는 Caddy가 붙여 주는 `X-Forwarded-For`로 실제 주소를 보고 주소별 제한을 셉니다. 8787이 열려 있으면 누구나 이 헤더를 꾸며 제한을 피할 수 있습니다. 차가 보낸 가짜 `X-Forwarded-For`는 Caddy가 버리고 실제 주소로 바꿉니다.
- **접속 기록은 남기지 않습니다**: Caddy와 uvicorn의 접속 기록을 꺼 두어 차의 IP 주소가 로그에 쌓이지 않습니다.
- **비용**: 실제 모델을 부르는 건 `/v1/episode`뿐입니다. 공개 주소라 누구나 부를 수 있으니, 비용이 걱정되면 `.env`의 `STORY_DAILY_PER_IP`를 낮추고 Gemini/Anthropic 콘솔에 월 사용 한도를 걸어 두세요.
- **출시 전**: Gemini API는 18세 미만 대상 서비스에 쓸 수 없습니다(`README.md`의 '모델과 정책'). 공모전 시연이 끝나고 실제로 공개하려면 작성 모델부터 바꿔야 합니다.
