# 차량탈출 AI 이야기 서버

차 앱이 정한 퍼즐 정답(규칙 엔진)을 받아, 그 정답에 맞는 루미의 대사를 Claude 또는 Gemini로 쓰고, 검사를 통과한 문장만 차로 돌려보냅니다.
AI는 정답을 정하지 않고 문장만 씁니다. 서버나 AI가 실패하면 차 앱은 앱 안의 기본 이야기(`Lines.kt`)로 그대로 진행합니다.

## 흐름

```
차 앱 (부모 준비 화면, 판이 시작될 때)
  └ POST /v1/episode  { 나이 단계, 시간, 계절, 정답 키 목록 }   ← 이름, 목소리, 위치, 자유 문장은 보내지 않음
       └ Claude 또는 Gemini (구조화 출력, 정해진 JSON 틀) → 검사기 → 통과한 장면만 응답
  ← 다음 판 이야기를 기기에 저장해 두었다가, 같은 설정으로 시작하면 바로 사용 (차 안에서 기다리지 않음)
```

- **정답 키**: `ROOMS:LEFT`(펭귄 방 왼쪽), `DUST:OUTSIDE`, `WIND:FACE:GENTLE`, `SEAT:REAR_LEFT`, `TOGETHER:SAME_TIME`, `FOG`, `BELT`.
  퍼즐을 시작할 때 차 상태 때문에 정답이 바뀔 수 있어서(`Planner.refresh`), 앱은 바뀔 수 있는 정답까지 함께 보내고 서버는 정답마다 장면을 씁니다.
- **검사기** (`app/checker.py`)
  1. 틀: 길이(가장 어린 나이 단계 기준), 빠진 장면
  2. 말: 무서운 말, 차에서 위험한 말(문, 창문 열기, 벨트 풀기, 출발, 기어 등), 개인정보 질문, 영어와 주소
  3. 정답 일치: 장면마다 정답 말(예: "왼쪽")이 있고 다른 정답 말(예: "오른쪽")이 없어야 함. 벨트 미션이 아닌 장면은 찾은 버튼을 "안전 지킴이"에게 가리켜 알려 주자는 말이 있어야 함
  4. 말풍선: 그림 옆 말풍선(bubble)에 버튼 이름("성에", "독서등" 등)이나 "켜기", "끄기"가 없어야 함. 선물 문장에는 "안전 지킴이"가 있어야 함
- **규칙 파일** (`app/story_rules.toml`): 길이 제한, 금지 패턴, 정답 키 20개마다 모델에게 알려 줄 장면 설명과 꼭 넣을 말, 쓰지 말 말이 모두 여기 있습니다. 작성기에게 알려 주는 말과 검사기가 확인하는 말이 같은 곳에서 나옵니다.
  서버가 시작할 때 파일을 검사해서, 모르는 항목 이름, 깨진 정규식, 빈 단어 묶음이 있으면 서버가 뜨지 않습니다(오타가 검사를 몰래 약하게 만들지 않도록). 바꾼 뒤에는 `pytest`로 서로 바뀔 수 있는 정답끼리 상대의 정답 말을 막는지도 확인합니다.
- 검사 부품(금지 패턴, 길이, 꼭 넣을 말, 판정 범위)과 표본 측정 명령은 [textgate](https://github.com/leekwangeun/textgate) 라이브러리를 씁니다. 나이별 말 길이와 안전 지킴이 규칙처럼 차량탈출에만 있는 규칙은 `app/checker.py`에 있습니다.
- 판 전체 문장(제목, 첫인사, 칭찬)에 문제가 있으면 그 초안은 버립니다. 장면 하나만 문제면 그 장면만 빼고, 차는 그 장면을 기본 문장으로 진행합니다. 한 번 더 써 보고 더 깨끗한 초안을 고릅니다.
- **기록**: `data/episodes.jsonl`(보낸 이야기), `data/reports.jsonl`(부모의 이야기 신고). 설치 ID는 기록하지 않습니다.
- **비용 제한**: 설치 하나당 하루 20편, 주소 하나당 하루 200편 (환경 변수로 조정)

## 이야기 소원과 그림 (맞춤 이야기)

- 부모 준비 화면의 **오늘의 이야기 소원**에 듣고 싶은 이야기를 한 문장(60자까지) 적거나 추천 칩을 고르면, 앱이 `wish`와 `pictures: true`를 보냅니다.
- 서버는 소원을 먼저 검사해서 무서운 말, 차에서 위험한 말, 개인정보가 있으면 모델을 부르지 않고 422(`wish_rejected`, 이유 포함)로 돌려보냅니다. 소원 글은 기록 파일에 남기지 않습니다(있었는지만 남김).
- 작가는 소원을 오늘의 세계로 삼아 이야기를 쓰고, `world`(세계 한 줄)와 `art`(표지, 퍼즐마다 한 장, 마지막 장면의 그림 설명)도 씁니다. 퍼즐과 정답은 그대로 규칙 엔진이 정합니다.
- 그림 설명에는 정답 단서(위쪽/아래쪽, 왼쪽/오른쪽, 안/밖, 자리 이름, 버튼 이름)가 들어가면 안 됩니다. 검사기(`checker.art_problems`)가 그런 설명을 빼고, 빠진 그림 자리는 앱의 기본 그림으로 나옵니다. 정답은 루미의 말로만 알려 줍니다.
- 그림은 Gemini 이미지 모델(`IMAGE_MODEL`, 기본 `gemini-nano-banana-2.1`)이 `app/art`의 참고 그림 3장(루미 표정, 친구 6명, 클레이 장면)을 보고 같은 캐릭터, 같은 그림체로 그립니다. 여러 장을 동시에 그리고, 실패한 그림만 빠집니다. 앱은 `GET /v1/images/{storyId}/{name}.webp`로 받아 기기에 저장합니다.
- `textgate`가 없으면 같은 검사를 하는 내장 모듈(`app/gate.py`)을 씁니다. 그래서 비공개 저장소 권한이 없어도 서버가 설치되고 시험이 모두 돕니다.
- 키 없이 흐름만 볼 때 `python -m tools.dev_server`는 소원을 제목에 넣고, 그림 자리에 색 카드를 그려 줍니다.

## 오늘의 새 친구 (친구 도감)

- 이야기마다 작가가 그 세계에 사는 새 친구 한 명(`friend`: 이름, 생김새, 성격, 인사말)을 같이 씁니다. 퍼즐의 주인공은 그대로 도감의 여섯 친구이고, 새 친구는 모험을 함께 다니다가 보물을 찾으면 앱의 친구 도감에 들어갑니다.
- 새 친구도 말풍선과 같은 규칙으로 검사합니다(`checker.friend_problems`): 우리말 이름 2~10자, 도감 친구·루미·탐험대장·안전 지킴이와 다른 이름, 무서운 말·버튼 이름·정답 단서 금지. 걸리면 친구만 빠지고 이야기는 그대로 나갑니다. 첫 원고에 쓸 만한 친구가 없으면 한 번 더 써 달라고 합니다.
- 화가가 있으면 소원이 없는 이야기에도 새 친구 얼굴(정사각형 1장, `images.friend`)은 그립니다. 장면 그림을 그릴 때는 얼굴을 먼저 그리고, 표지와 마지막 장면은 그 얼굴을 참고 그림으로 함께 받아 같은 친구로 그립니다.
- 그림은 과한 3D 렌더 대신 손으로 빚은 점토 인형을 찍은 느낌으로 그리게 하고, 반짝임·빛 번짐·배경 흐림·과한 장식 같은 'AI 그림 티'는 매번 금지합니다(`painter.py`의 `LOOK`, `NOT_AI`).

## 실행

```powershell
cd escape\server
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env      # ANTHROPIC_API_KEY 또는 GEMINI_API_KEY 입력 (저장소에 올리지 않음)
.\.venv\Scripts\python -m uvicorn app.main:app --env-file .env --host 127.0.0.1 --port 8787
```

에뮬레이터의 차 앱은 `http://127.0.0.1:8787`로 접속하므로 PC로 포트를 넘겨 줍니다.

```powershell
adb reverse tcp:8787 tcp:8787
```

배포한 서버를 쓰는 APK는 `-PstoryUrl=https://주소`로 빌드합니다.

## 시험

```powershell
.\.venv\Scripts\python -m pytest -q          # 검사기, API, 작성기 (실제 모델을 부르지 않음)
.\.venv\Scripts\textgate sample tools.story_spec:SPEC -n 30                 # 실제 모델로 30편: 통과율, 실패 원인, 시간, 토큰 수, 비용 (유료 호출)
.\.venv\Scripts\textgate recheck tools.story_spec:SPEC "data/sample-*.jsonl"  # 저장된 초안을 지금 규칙으로 다시 판정 (호출 없음, 무료)
.\.venv\Scripts\textgate try app/story_rules.toml "커피가 따뜻해"              # 문장 하나가 어떤 금지 패턴에 걸리는지
.\.venv\Scripts\python -m tools.dev_server   # 키 없이 앱 연결만 확인하는 개발용 서버 (문장에 [개발용] 표시)
```

## 모델과 정책

- 시제품 모델: Gemini `gemini-3.6-flash`. 정해진 JSON 틀(`response_json_schema`)로 받고 `thinking_level: LOW`로 기다림을 줄입니다(한 편에 대개 5~10초). Google 쪽이 붐비거나 분당 횟수 제한에 걸리면 몇 초 뒤 최대 두 번 다시 요청합니다. `.env`에 `GEMINI_API_KEY`가 있으면 Gemini를 씁니다.
- 작성기(`app/writer.py`)는 바꿔 끼울 수 있게 나뉘어 있습니다. Claude(`claude-opus-5-5`)도 들어 있어 `STORY_PROVIDER=claude`와 `ANTHROPIC_API_KEY`만 넣으면 바뀌고, 모델 이름은 `STORY_MODEL`로 바꿉니다. 어떤 모델이 쓰든 같은 검사기를 거칩니다.
- 출시 전 교체: Gemini API 약관은 18세 미만을 대상으로 하거나 18세 미만이 이용할 가능성이 높은 서비스에 API를 쓰는 것을 허용하지 않습니다. 그래서 실제 출시 때는 Pleos 차량 인앱 LLM(앱용 SDK가 공개되면) 또는 미성년자 서비스를 허용하는 제공사(예: Anthropic, 안전장치를 갖추는 조건)로 작성기를 바꿉니다.
- 결제를 켠 유료 등급으로 호출하므로 보낸 입력과 출력은 Google의 제품 개선에 쓰이지 않습니다. 서버는 정답 키, 나이 단계, 시간대, 계절만 보내고 아이에 대한 정보는 보내지 않습니다.
- 아이는 AI와 직접 대화하지 않고 검사를 통과한 문장만 듣습니다. 앱은 시작 화면에 AI가 만든 이야기임을 알리고, 부모 화면에 이야기 신고 버튼을 둡니다.
