# 차근차근 탐험단 룰북

2026-11-26 · 문현웅

차근차근 탐험단은 주차한 차 안에서 아이가 친구와 함께 문제를 풀고, 그 답을 **차의 진짜 버튼**으로 넣는 탐험 놀이예요. 아이는 답을 말하고 버튼을 가리키며, 운전석의 보호자(앱에서는 "안전 지킴이")가 확인하고 버튼을 눌러 줍니다.

## 이 룰북 읽는 법

- **보호자용** 장(준비, 부모 화면, 안전, 문제 해결)은 시작 전에 보호자가 먼저 읽어 주세요.
- **아이용** 장(탐험 순서, 문제 푸는 법)은 쉬운 말로 썼어요. 아이에게 소리 내어 읽어 주거나 인쇄해서 보여 주세요.
- [그림: …] 표시는 화면 캡처나 그림이 들어갈 자리예요.
- 화면은 왼쪽이 **부모 화면**, 오른쪽이 **아이 화면**이에요. 세로 화면에서는 위가 아이 화면, 아래가 부모 화면이에요.

[그림: 앱 전체 화면. 왼쪽 부모 화면, 오른쪽 아이 화면에 표시]

| 한눈에 보기 | |
| --- | --- |
| 누가 | 아이(4~12세) + 운전석 보호자 |
| 언제 | 주차(P)·충전 중에 기다릴 때, 5·10·15분 |
| 몇 문제 | 5분 3개, 10분 4개, 15분 5개 (벨트 미션 포함). 차에 있는 장치가 적으면 줄 수 있어요 |
| 끝나면 | 보물까지 찾으면 탐험 배지와 함께한 친구 하트 +1, 차 설정은 앱이 원래대로 |

## [보호자] 시작 전 준비

아래 네 가지가 모두 맞아야 [시작] 버튼이 눌려요. 하나라도 안 맞으면 준비 화면에 빨간 안내 문구가 뜨고 버튼이 잠겨요.

| 조건 | 안 맞을 때 화면 문구 |
| --- | --- |
| 기어 P, 차가 멈춰 있음 | 기어를 P로 두면 이어서 할 수 있어요 |
| 문 4개 모두 닫힘 | 문이 닫히면 이어서 할 수 있어요 |
| 운전석에 보호자가 앉음 | 운전석에 보호자가 앉아 있어야 시작할 수 있어요 |
| 공조 전원 켜짐 | 공조 전원을 켜야 시작할 수 있어요 |

머리줄의 **주차 중**, **운전석 보호자**가 켜지고, 준비 화면에 빨간 안내가 하나도 없으면 시작할 수 있어요. 머리줄에는 이 두 가지만 보이니 문과 공조 전원은 빨간 안내로 확인해 주세요.

[그림: 머리줄의 ‘주차 중’·‘운전석 보호자’ 표시]

### 준비 화면에서 고를 것 (“시작하기 전에 골라 주세요”)

1. **오늘의 이야기 소원** (고르지 않아도 돼요)
    - **장소**를 적고(예: 공룡 섬, 20자까지) **이야기 종류**를 골라요: 보물찾기, 구조대, 탐정 놀이, 고장 수리, 축제 준비, 발명 대회.
    - [소원 빌기]를 누르면 AI가 오늘 퍼즐에 맞춰 이야기와 그림을 새로 만들어요. 보통 30초쯤 걸려요.
    - 아이 이름이나 사는 곳은 적지 마세요.
2. **함께할 친구**: 아이 화면 아래 친구 도감에서 아이가 직접 골라요(아래 아이용 장 참고).
3. **아이 나이**: 4~6세 꼬마 탐험대 / 7~9세 탐험대장 / 10~12세 수석 탐정 중 하나. 문제의 난이도가 달라져요.
4. **기다릴 시간**: 5분(퍼즐 3개) / 10분(퍼즐 4개) / 15분(퍼즐 5개).
5. **아이 화면 자막**: 친구가 하는 말을 아이 화면에 글자로도 보여 줘요. 기본은 켜짐이고, 누를 때마다 켜짐/꺼짐이 바뀌며 다음에도 기억해요.
6. 맨 아래 큰 버튼으로 시작해요. 버튼 이름은 이야기 상태에 따라 달라요.

| 버튼 이름 | 뜻 |
| --- | --- |
| 이 이야기로 시작하기 | AI 이야기가 준비됨 |
| 기다리지 않고 기본 이야기로 시작 | AI 이야기를 만드는 중. 누르면 기본 이야기 ‘별빛 기차’로 바로 시작 |
| 기본 이야기로 시작하기 | AI 이야기가 없음(서버에 연결하지 못했거나, 소원이 막혔거나, 아직 만들기 전) |

[그림: 준비 화면(부모 화면) 전체]

### 시작하면 꼭 해 주세요

- **아이는 뒷좌석 오른쪽에 앉혀 주세요.** 앱은 아이가 뒷좌석 오른쪽에 앉아 있다고 보고 ‘아이 자리 독서등’ 문제를 내요(자리를 바꾸는 화면은 없어요).
- 아이는 벨트를 맨 채로 해요.
- **공조 AUTO를 꺼 주세요.** AUTO가 바람, 에어컨, 내기 순환을 저절로 바꿔서 정답 판정이 틀어져요. 친구도 첫인사에서 “안전 지킴이, 공조 오토를 꺼 주세요”라고 말해요.

## [함께] 놀이 전 약속

시작하기 전에 보호자와 아이가 함께 읽어 주세요. 이 놀이는 **공조 버튼과 독서등만** 써요. 차를 움직이는 장치는 하나도 쓰지 않아요.

### 이 놀이에서 쓰지 않는 것

| 쓰지 않아요 | 왜냐면 |
| --- | --- |
| 브레이크 페달, 액셀 페달 | 문제에 나오지 않아요. 보호자는 발을 페달에서 떼 두세요 |
| 핸들 | 문제에 나오지 않아요 |
| 기어 | 놀이 내내 P에 둡니다. P에서 빼면 앱이 멈춰요 |
| 시동 버튼 | 놀이 중에 누르지 않아요 |
| 문과 창문 | 문을 열면 앱이 멈춰요. 창문 버튼도 누르지 않아요 |
| 안전벨트 풀기 | 벨트는 끝까지 매고 있어요 |
| 경적, 비상등, 전조등 | 문제에 나오는 불은 천장의 독서등뿐이에요 |

### 이 놀이에서 쓰는 것

바람 세기(풍량), 온도, 독서등, 시트 열선, 에어컨, 내기 순환, 앞 유리 성에 제거. 버튼은 보호자가 눌러요. 아이는 손이 닿는 자기 자리 독서등만 직접 눌러도 돼요.

[그림: 쓰는 버튼(초록 동그라미)과 쓰지 않는 장치(빨간 X)를 표시한 차 안 그림]

### 탐험대장의 약속 (아이와 같이 읽어요)

1. 나는 내 자리에 앉아 벨트를 매고 있어요.
2. 버튼은 손가락으로 가리키고, 누르는 건 안전 지킴이가 해요.
3. 앞자리로 넘어가지 않아요.
4. 문이나 창문을 열지 않아요.
5. 화면은 친구를 고를 때만 눌러요.
6. 힘들거나 덥거나 추우면 바로 안전 지킴이에게 말해요.

### 보호자 확인 (시작 전 30초)

- [ ] 기어 P, 발은 페달에서 떼기
- [ ] 문과 창문 닫힘, 아이는 뒷좌석 오른쪽에 벨트 맨 채로
- [ ] 공조 전원 켜기, 공조 AUTO 끄기
- [ ] 주변이 안전한 곳에 주차했는지 확인(차가 다니는 길가나 출구 앞은 피하기)
- [ ] 실내 주차장에서는 오래 시동을 켜 두지 않기. 공기가 답답하면 외기로 두거나 놀이를 멈추기

## [아이] 친구와 함께하는 탐험 순서

안녕, 탐험대장! 오늘은 친구와 함께 문제를 풀고, 답을 차의 진짜 버튼으로 넣어 보자. 운전석에 앉은 어른은 우리를 지켜 주는 **안전 지킴이**야.

1. **친구를 골라요.** 화면 아래 ‘친구 도감’에서 오늘 함께할 친구를 눌러요. 고른 친구에는 ‘함께해요’가 떠요.
    - [그림: 친구 도감]
2. **이야기를 들어요.** 친구가 “나는 ○○야!” 하고 오늘의 모험을 들려줘요. 글자도 화면 아래에 나와요.
3. **문제를 풀어요.** 친구가 문제를 내요. 숫자 문제는 화면에 크게 나와요(예: 1 + 2 = ?).
    - [그림: 문제 카드가 뜨는 아이 화면]
4. **버튼을 찾아 가리켜요.** 답을 찾으면 어느 버튼을 어떻게 바꿀지 안전 지킴이에게 말해 줘요. 안전 지킴이가 버튼을 눌러 줘요.
5. **하나, 둘, 셋 기다려요.** 버튼을 바꾸고 셋을 셀 동안 그대로 두면 “정답! 별 하나 획득!” 별이 하나 생겨요.
6. **벨트 딸깍 미션!** 두 문제를 풀고 나면 벨트를 딸깍 매는 미션이 있어요. 이미 매고 있으면 버클을 손으로 짚고 “딸깍 확인!”을 외쳐요.
7. **보물을 열어요.** 문제를 모두 풀면 “탐험 배지 획득!” 배지를 받아요.
8. **친구와 더 친해져요.** 보물까지 모두 찾으면 함께한 친구의 하트가 하나 차요. 하트는 5개까지 모을 수 있어요.

화면 맨 위 구슬을 보면 몇 문제 남았는지 알 수 있어요. 끝에 있는 것이 보물이에요.

> 팀 최신 코드를 합치면 들어갈 내용: **틀려도 괜찮아!** 다른 버튼을 누르거나 너무 많이·반대로 바꾸면 친구가 “음, 그 버튼은 아닌 것 같아. 다시 생각해 볼까?”처럼 부드럽게 알려 줘요. (지금 gemini-tts 브랜치에는 아직 없는 기능)

### 친구들을 소개할게

| 친구 | 동물 | 이런 친구야 | 하는 말 |
| --- | --- | --- | --- |
| 반테 | 강아지 | 용감해요 | 먼저 해볼래! |
| 코냥 | 고양이 | 잘 살펴봐요 | 자세히 보면 보여 |
| 리아 | 토끼 | 상상을 잘해요 | 이렇게 생각해 보면 어때? |
| 투부기 | 거북이 | 포기하지 않아요 | 천천히 해도 괜찮아 |
| 파삐 | 뱁새 | 같이 해요 | 같이 하면 할 수 있어 |
| 포또 | 판다 | 나눠 줘요 | 나눠 먹자 |

[그림: 친구 6명 얼굴]

**비밀 친구도 있어!** 도감에는 회색 그림자만 보이는 ‘누구일까?’ 친구가 3명 있어요. 친구 하트를 5개 모두 채우면 그 친구 위에 “새로운 친구를 만나러 가자!” 말풍선이 떠요. 눌러 보면 비밀 친구가 탐험단에 들어와요.

## [아이] 문제 푸는 법

문제는 네 가지야. 답을 찾으면 언제나 **차 버튼**으로 넣어.

| 문제 | 이렇게 나와 | 답을 넣는 법 |
| --- | --- | --- |
| 계산 문제 | “바람 세기를 1 더하기 2단으로 맞춰 줘!” | 1 + 2 = 3 → 바람 3단 |
| 영어 문제 | “바람 세기를 ONE단으로 맞춰 줘!” | ONE은 1 → 바람 1단 |
| 영어 글자 수 | “켜진 독서등이 SUN의 글자 수만큼 되게 해 줘!” | S-U-N은 3글자 → 독서등 3개 |
| 규칙 찾기 | “바람 세기를 4단, 3단, 2단 다음 단으로 맞춰 줘!” | 하나씩 작아져 → 바람 1단 |
| 생각 문제 (친구 도와주기) | “내 몸이 으슬으슬 떨려. 차 버튼으로 나를 도와줘!” | 추우니까 → 온도 올리기 |

계산·영어·규칙 찾기 문제는 화면에 큰 카드로도 나와요. 예: “1 + 2 = ?”, “ONE = ?”, “SUN 몇 글자?”, “4, 3, 2, ?”. 생각 문제는 친구 말을 잘 들어요.

### 문제에 나오는 차 버튼

차마다 있는 버튼만 문제에 나와요. 한 판에서 같은 버튼은 한 번만 나와요.

| 버튼 | 무엇을 바꿔? | 이럴 때 써 |
| --- | --- | --- |
| 바람 세기 (풍량) | 바람이 몇 단인지 | 더워요, 바람이 너무 세요 |
| 온도 (운전석 온도) | 숫자가 커지면 따뜻, 작아지면 시원 | 추워요, 더워요 |
| 천장 불 (독서등) | 불을 몇 개 켤지, 내 자리 불 | 책을 읽고 싶어요, 너무 눈부셔요 |
| 따뜻한 의자 (시트 열선) | 운전석 의자가 따뜻해져 | 엉덩이가 차가워요 |
| 시원한 바람 (에어컨) | 차가운 바람 | 너무 더워요, 이제 추워요 |
| 바깥 공기 막기 (내기 순환) | 밖 공기를 막거나 들여와 | 밖에서 냄새가 나요, 답답해요 |
| 뿌연 유리 닦기 (앞 유리 성에 제거) | 뿌연 유리창을 맑게 | 앞이 안 보여요 |

[그림: 우리 차 공조 버튼과 독서등 위치]

### 꼭 기억해

- 버튼은 **손가락으로 가리키고** 안전 지킴이에게 부탁해요. 자리에서 일어나거나 앞으로 넘어오지 않아요.
- 독서등 개수 문제는 손이 닿는 내 자리 불은 직접 켜고, 나머지는 몇 개 켤지 안전 지킴이에게 부탁해요.
- 모르겠으면 “힌트 주세요!” 하고 말해요. 안전 지킴이가 [힌트 듣기]를 눌러 줘요.
- 답을 넣고 하나, 둘, 셋 셀 동안 그대로 두어야 정답이 돼요. 지나가면서 잠깐 맞는 것은 안 세요.

## [보호자] 부모 화면 쓰는 법

부모 화면은 ‘안전 지킴이 · 부모님’ 표시가 있는 왼쪽 칸이에요. 정답은 AI가 아니라 앱의 규칙 엔진이 정하고, AI는 그 정답에 맞는 이야기만 써요.

### 화면별 버튼

| 화면 | 보이는 것 | 누를 버튼 |
| --- | --- | --- |
| 오늘의 이야기 | 이야기 제목, 오늘의 퍼즐 목록, ‘공조 AUTO를 꺼 주세요’ 안내, 이야기 신고(AI 이야기일 때) | [탐험 시작] |
| 퍼즐 중 | 퍼즐 제목, ‘이 퍼즐에서 쓰는 버튼’ 그림, 정답 보기, 안전줄 | [다시 듣기] [힌트 듣기] [끝내기] [멈춤] |
| 벨트 딸깍 미션 | ‘아이가 스스로 매도록 기다려 주세요’ | [확인했어요] [끝내기] [멈춤] |
| 정답이에요! | ‘아이를 듬뿍 칭찬해 주세요’ | [다음 퍼즐] 또는 [보물 열기], [멈춤] |
| 탐험 배지를 받았어요 | 함께한 친구의 하트. 5개를 채우면 ‘하트를 다 채웠어요! 친구 도감에서 새 친구를 만날 수 있어요’ | [처음 설정으로] |

[그림: 퍼즐 중 부모 화면]

**안전줄**은 화면 아래쪽 한 줄이에요. 주차 · 문 닫힘 · 운전석이 지금 맞는지 체크 표시로 보여 주고, 오른쪽에 놀이한 시간(예: 03:12 / 20:00)이 나와요.

### 자주 쓰는 기능

- **정답 보기 (길게 누르기)**: 점선 칸을 길게 누르면 정답이 나와요. 아이가 우연히 보지 않게 짧게 눌러서는 안 열려요. 예: “정답: 풍량 1단 (3 - 2 = 1)”, “정답: 운전석 온도를 퍼즐 시작 때보다 2도 올리기, 지금 22도에서 24도로”.
- **다시 듣기**: 친구가 마지막에 한 말을 다시 들려줘요.
- **힌트 듣기**: 친구가 힌트를 말해 줘요. 정답은 말하지 않아요.
- **아이 화면 자막 켜짐/꺼짐**: 준비 화면과 퍼즐 중 화면에 있어요. 자막은 아이 화면에만 나오고, 주차(P)가 아닐 때는 숨겨져요. 소리가 없는 말은 꺼 두어도 글자로 보여요.
- **확인했어요 (벨트 미션)**: 앱은 벨트를 읽지 않아요. 아이가 딸깍 매는 것을 보호자가 눈으로 확인하고 눌러 주세요.
- **이야기 신고**: AI 이야기가 이상하면 [무서워요] [정답과 달라요] [말이 어려워요] 중에 눌러요. ‘오늘의 이야기’ 화면과 ‘처음 설정으로’ 화면에 있고, AI 이야기일 때만 보여요(퍼즐 중에는 없어요). 게임은 멈추지 않아요.
- **처음 설정으로**: 끝나면 앱이 공조(내기 순환, 풍량, 풍향, 좌우 온도, 성에 제거, 에어컨)와 독서등, 운전석 열선을 게임 전대로 되돌려요. 못 되돌린 항목은 목록으로 남으니 직접 돌리고 [다 돌렸어요]를 눌러 주세요.

### 앱이 차를 바꾸는 때

게임 중에는 앱이 차를 **읽기만** 해요. 버튼은 항상 보호자가 눌러요. 앱이 차를 바꾸는 건 끝낼 때([처음 설정으로], [끝내기], [다시 되돌리기])뿐이고, 주차(P)일 때만 해요.

## [보호자] 안전 규칙과 앱이 멈추는 경우

차 때문에 멈추면 ‘잠깐 쉬어요!’ 화면이 뜨고 친구가 “잠깐 쉬어 갈게. 다시 준비되면 이어서 하자!”라고 말해요. [멈춤]을 누르면 ‘잠깐 멈췄어요’ 화면이 뜨고 친구는 조용히 기다려요.

| 멈추는 일 | 화면 문구 | 다시 하려면 |
| --- | --- | --- |
| 기어를 P에서 빼거나 차가 움직임 | 기어를 P로 두면 이어서 할 수 있어요 | P로 두면 **저절로 바로 이어져요** |
| 문이 하나라도 열림 | 문이 닫히면 이어서 할 수 있어요 | 문을 닫으면 **저절로 바로 이어져요** |
| 놀이한 시간 20분 | 20분이 지났어요. 잠깐 쉬어요 | [이어 하기]가 막혀요. [끝내기]로 마치기 |
| 보호자가 [멈춤]을 누름 | 잠깐 멈췄어요 / 준비되면 이어 하기를 눌러 주세요 | [이어 하기] |

**주의: P로 두거나 문을 닫는 순간 멈춤 화면이 사라지고 바로 이어져요.** 아이가 자리에 앉아 벨트를 맸는지 먼저 확인한 뒤 P로 두거나 문을 닫아 주세요. 친구의 말은 [다시 듣기]로 다시 들을 수 있어요.

멈춰 있는 동안에는 뒤에 있는 버튼(다음 퍼즐, 힌트 등)이 눌리지 않아요. [끝내기]는 언제든 눌리고, 누르면 차 설정을 되돌리고 끝내요.

### 보호자가 지켜 주세요

- 운전석에는 늘 보호자가 앉아 있어야 해요. 앱은 시작할 때만 운전석을 확인해요. 게임 중에 자리를 비워도 앱은 멈추지 않아요.
- 차 버튼은 보호자가 눌러 주세요. 아이는 가리키기만 하고 앞자리로 넘어오지 않게 해 주세요.
- 아이는 벨트를 맨 채로 해요. 앱은 벨트를 읽지 못하니 보호자가 확인해 주세요.
- ‘내기 순환 3분이 지났어요. 외기로 돌려 주세요’가 뜨면 외기로 바꿔 주세요. 오래 켜 두면 창에 김이 서리고 공기가 탁해져요.
- 닫힌 차 안에 아이를 혼자 두지 마세요. 이 앱은 보호자가 함께 있을 때만 쓰는 놀이예요.
- 소원에 아이 이름, 사는 곳, 전화번호를 적지 마세요. 무서운 말이나 차 안전에 어긋나는 말(문 열기, 벨트 풀기 등)이 들어간 소원은 ‘이 소원은 다르게 적어 주세요’로 막혀요.
- AI가 쓴 문장은 앱에 들어오기 전에 무서운 말, 차 안전, 개인정보, 정답 일치 검사를 거쳐요. 아이는 AI와 직접 대화하지 않아요.

## [보호자] 문제 해결

| 이럴 때 | 이렇게 해 주세요 |
| --- | --- |
| 시작 버튼이 안 눌려요 | 준비 화면의 빨간 안내를 보고 기어 P, 문 닫기, 운전석 착석, 공조 전원을 맞춰 주세요. |
| 공조 전원을 켰는데 빨간 안내가 남아요 | 앱이 차 값을 다시 읽는 중이에요. 몇 초 기다려 주세요. |
| ‘차량 장치(공조, 독서등)를 아직 읽지 못했어요’ | 앱이 차와 연결되는 중이에요. 몇 초 기다려 주세요. |
| 버튼을 눌렀는데 정답이 안 돼요 | 1) 공조 AUTO가 꺼져 있는지 보세요. 2) 정답 값에서 3초쯤 그대로 두세요. 3) [정답 보기]를 길게 눌러 정답을 확인하세요. |
| 온도 문제가 안 풀려요 | 온도 문제는 **운전석 온도**를 봐요. ‘퍼즐 시작 때보다’ 얼마나 바꾼지로 세요. 정답 보기에 ‘지금 22도에서 24도로’처럼 나와요. |
| 독서등 문제가 안 풀려요 | ‘독서등 모두 ○개’는 켜진 등의 수를 봐요. ‘아이 자리’는 뒷좌석 오른쪽 등이에요. |
| 문제가 갑자기 바뀌었어요 | 퍼즐을 시작할 때 차가 이미 정답 상태면, 아이가 직접 바꿀 수 있는 다른 문제로 바꾸거나 그 퍼즐을 건너뛰어요. 정상이에요. |
| 퍼즐 수가 고른 것보다 적어요 | 차에 있는 장치가 적으면 퍼즐 수가 줄어요. 차 문제가 1개뿐이면 벨트 미션도 빠져요. |
| 친구 목소리가 안 나와요 | 친구 목소리는 이야기 서버에서 받아요. 인터넷이 안 되면 이야기는 그대로 하지만 목소리 없이 자막으로만 나와요(자막을 꺼 두어도 보여요). 차의 음량도 확인해 주세요. |
| 목소리가 늦게 나와요 | 처음 듣는 말은 목소리를 받는 동안 몇 초 늦게 나올 수 있어요. 그동안 자막이 먼저 나와요. |
| AI 이야기가 안 만들어져요 | ‘이야기 서버에 연결하지 못해 기본 이야기로 해요’가 뜨면 기본 이야기 ‘별빛 기차’로 끝까지 할 수 있어요. |
| ‘이 소원은 다르게 적어 주세요’ | 괄호 안 이유를 보고 다른 장소를 적거나 [소원 지우기]를 눌러요. |
| 끝낸 뒤 차 설정이 그대로예요 | ‘주차(P)한 뒤 다시 되돌려 주세요’가 떴다면 P로 두고 [다시 되돌리기]. 그래도 남은 항목은 직접 돌려 주세요. |
| 화면이 사라졌어요(주행 중) | 주행 중에는 차가 앱을 가려요. 주차(P)하면 앱이 다시 보이고 저절로 이어져요. |
